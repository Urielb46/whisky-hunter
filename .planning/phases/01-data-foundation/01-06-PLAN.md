<objective>
Seed the canonical product catalog from Whiskybase (15,000+ bottles) and keep community scores + images fresh on a weekly cadence. Surface Whiskybase scores, vote counts, and attribution links on all product detail pages (web + mobile).

Purpose: WBASE-01–04 add Whiskybase as the authoritative product catalog source, replacing the hand-curated bootstrap seed. The catalog gives users community-validated scores and bottle images before retailer scrapers even run — critical for the Internal Alpha milestone.
Output: Schema migration, catalog adapter, seed CLI, weekly refresh BullMQ job, API and UI updates.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation |

| T-01-06-01 | DoS | Whiskybase rate limit | mitigate | Adapter enforces 2s + jitter per request; BullMQ rate limit set to 1 req / 2s per worker |
| T-01-06-02 | Legal | ToS violation | mitigate | robots.txt check in adapter; rate limit 1/2s; data partnership outreach (P0-04) |
| T-01-06-03 | Tampering | Malicious wb_score from scraped page | mitigate | Score validated 0–100 float before upsert; control-char rejection on whiskybase_id |
</threat_model>
